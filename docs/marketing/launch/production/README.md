## One-session recording plan (all app footage in ~90 minutes, one device)

Do these in order on the demo account (`appreview@getvault.app`) — the capture-readiness state is prepared, see `store/screenshot-plan.md`:

1. **Day-before pass (5 min):** complete 1–2 moves so tomorrow's delta/streak render (needed by V22; same prep serves screenshot frames 2/4).
2. **Signed-out pass:** V21 Rec A — uncut onboarding → reveal → gaps (3 takes).
3. **Signed-in pass:** V22 Rec A — full Daily Open → Vault Closed (one continuous take) · V01 Rec B — idle-cash card → completion · V07 Rec A — 3s static hold on the idle-cash card.
4. **Settings pass:** V24 Rec A (Plaid consent hold) + Rec B (Settings → delete-account confirmation → cancel).
5. B-roll (coffee, commute window, ceiling) any time — phone-shot, no faces.

All five videos are producible **without the founder's face**. Voiceover: calm founder read or quality TTS for the text-led cuts (V07 deserves a human read).

Export masters to `exports/{video}/` (git-ignored, local) using each package's naming convention.
