# V07 · The Anthem — Production Package

**Role in launch:** the identity flag — tells the segment this is *their* app. TOFU flagship. **No face required** — text-on-screen over muted b-roll.
**Recommended duration:** 30–33s. Reels-first.

## Final script / voiceover text (~30s, quiet, unhurried — the anti-hype read)

> You did the things. Degree, job, the salary that would have amazed 19-year-old you. And still — every money thought ends in the same fog. You're not reckless. Nothing's on fire. You're just… drifting, at altitude. Here's the part nobody says: you were never taught *next*. You were taught save more, spend less — a direction, not a step. VAULT was built for exactly this feeling. It reads your accounts and says: here. This. Today. That's the whole app.

## Editing timeline

Slow cuts (2–3s holds), no transitions but straight cuts, type set in the serif (Cormorant) on black. VO carries; music is a single sustained pad, −20LUFS. The only "product" is the final 3 seconds — resist adding more UI. End card: wordmark + getsvault.com, no button language.
