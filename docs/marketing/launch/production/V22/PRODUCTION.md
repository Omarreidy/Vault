# V22 · The Daily Open (full flow) — Production Package

**Role in launch:** the mechanism video — converts curiosity into "I get it." MOFU→BOFU. **No face required** — screen recording + coffee b-roll bookends (hands optional, no face).
**Recommended duration:** 28–31s.

## Final script / voiceover text (~28s)

> Morning. Open the vault. First: what changed since yesterday — score delta, anything new. Then the hand: today's moves, sorted by impact. This one's worth the most — do it now. This one's a review — skim, done. Third one closes the vault. Seal, streak, done for the day. The app is *finished*. No feed to keep scrolling, nothing left to check. Tomorrow it deals again.
